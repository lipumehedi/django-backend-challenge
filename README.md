# Django Backend Challenge

## Overview

This repository documents my journey of learning and building backend applications with **Django and Python**.

The goal is to start from Django fundamentals and gradually build practical backend applications using Django, Django REST Framework, PostgreSQL, authentication, testing, and Docker.

This repository focuses on learning by building real projects and improving backend development skills step by step.

---

## Learning Goals

* Learn Django from beginner level
* Understand Django project and app structure
* Build web applications with Django
* Understand URLs, Views, and Templates
* Work with Django Models and ORM
* Use PostgreSQL with Django
* Build CRUD applications
* Implement authentication and authorization
* Build REST APIs with Django REST Framework
* Write backend tests
* Learn Docker for backend development
* Build real-world backend projects
* Improve Git and GitHub workflow
